# 志愿填报工作台

高考志愿填报公益辅导工具 · 知识可视化单页应用（零依赖、离线可用）。

## 四个模块

1. **分省份高校解读** — 上海 / 广东双省切换，含产业概览、主力院校、其他本科、民办·专科、报考策略、央国企对照、宿舍食堂
2. **专业解读** — 10 个热门专业：学什么 / 就业方向 / 选科要求 / 适合谁 / 代表院校
3. **梯度选校清单** — 输入分数自动生成冲·稳·保三栏清单，勾选汇总、一键复制
4. **模拟志愿填报** — 输入分数/位次，可视化展示冲稳保梯度与院校层次分布

## 特点

- 单文件 HTML，零外部依赖，断网可用
- 冲稳保分差算法：冲 −15~0 / 稳 0~10 / 保 10~35
- 数据为模拟/示例，真实填报请以省考试院当年公布为准
